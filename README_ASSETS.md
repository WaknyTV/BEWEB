# Guide des assets BE WEB

Tous les fichiers sont dans `assets/images/` avec une organisation par page.

## Global
- `assets/images/global/logo.svg` = logo principal (header).
- `assets/images/global/logo-dark.svg` = logo clair pour footer.
- `assets/images/global/favicon.png` = favicon.
- `assets/images/global/og-image.jpg` = image OpenGraph par défaut.

## Accueil
- `assets/images/home/hero.jpg` = image hero page Accueil.
- `assets/images/home/section-services.jpg` = visuel section “Pourquoi BE WEB”.
- `assets/images/home/proof-1.jpg` = visuel conversion (devis rapide).
- `assets/images/home/proof-2.jpg` = réserve pour preuve sociale (optionnel).

## Services
- `assets/images/services/header.jpg` = image hero page Services.
- `assets/images/services/service-web.jpg` = visuel service site vitrine.
- `assets/images/services/service-seo.jpg` = visuel service SEO local.
- `assets/images/services/service-social.jpg` = visuel service réseaux sociaux.

## Réalisations
- `assets/images/realisations/cover-template.jpg` = couverture portfolio.
- `assets/images/realisations/projet-1.jpg` = projet 1.
- `assets/images/realisations/projet-2.jpg` = projet 2.
- `assets/images/realisations/projet-3.jpg` = projet 3.
- `assets/images/realisations/projet-4.jpg` = projet 4.

## Avis
- `assets/images/avis/client-1.jpg` = visuel avis clients (hero).
- `assets/images/avis/client-2.jpg` = image avis optionnelle.
- `assets/images/avis/client-3.jpg` = image avis optionnelle.

## À propos
- `assets/images/about/team.jpg` = visuel équipe.
- `assets/images/about/workshop.jpg` = visuel atelier.

## Contact
- `assets/images/contact/map.jpg` = visuel localisation.

## Conseils format
- Format recommandé : JPG 1920x1080.
- Poids optimisé web (moins de 400 Ko).
- Remplacer les placeholders par vos images finales en conservant les noms.
